# Obsidian community plugins

Plugins from the work vault (kpdx). Settings are in `.obsidian/plugins/<id>/data.json` in each vault. The nested items show the settings that I changed.

- Templater (`templater-obsidian`)
  - Template folder location: `templates`
  - Template hotkeys: `templates/new_structure.md`, with "Create" on and "Insert" off
- Auto Reveal in Explorer (`auto-reveal-in-explorer`)
  - Auto reveal: on, reveal delay 50 ms
- Open Tab Settings (`open-tab-settings`)
  - Open in new tab: on
  - Deduplicate tabs: on, also across tab groups
  - New tab placement: after the active tab
  - Preview tabs: off
- Hider (`obsidian-hider`)
  - Hide status bar: on
  - Hide sidebar toggle buttons: on
  - Hide vault name: on
- Snipsy (`snipsidian`)
  - Snippets: `h2` (`## `), `h3` (`### `), `TODO` (`- [ ] `), `DONE` (`- [x] `)
- Unique Tab Labels (`unique-tab-labels`)
  - Default settings
- Advanced URI (`obsidian-advanced-uri`)
  - Default settings
- Pi Session (`pi-session`)
  - Not in the community store. Source: https://github.com/iamkahvi/obsidian-pi-session
  - Card layout: compact
  - Open target: `rex`
  - Pi executable: `~/.local/state/tec/toolchain/base_profile/bin/pi` (work Mac path)
